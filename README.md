HR Analytics & Workforce Intelligence Analysis

Project Overview

This project focuses on analyzing employee data to generate meaningful HR insights using Microsoft SQL Server and Power BI.

The goal is to understand workforce distribution, salary patterns, employee hiring trends, and department-wise performance through SQL analysis and interactive dashboards.

Tools & Technologies

- Microsoft SQL Server
- SQL
- Microsoft Power BI
- Data Visualization
- Excel/CSV (if applicable)

SQL Analysis

The project includes:

- Department-wise Employee Count
- Department-wise Salary Analysis
- Employee Salary Ranking using RANK()
- Department-wise Ranking using PARTITION BY
- Employee-Manager Analysis using SELF JOIN
- Job Title and Salary Range Analysis using CASE
- Year-wise Hiring Trends
- Country and Region-wise Workforce Analysis
- Subqueries and Common Table Expressions (CTEs)
- Employee Tenure Analysis
- Department-wise Top Earners
- HR Summary Report

Power BI Dashboard

The interactive dashboard includes:

- Department-wise Employee Count
- Department-wise Average Salary
- Employee-wise Salary Ranking
- Year-wise Hiring Trend
- Department-wise Total Salary
- KPI Cards: Total Employees, Average Salary, Highest Salary
- Interactive Department Slicer
